## G-01　安全性 / 行为闭环缺失（危害等级最高）

**触发信号（任一命中即须核查）**
- 开头或 A 段出现读者顾虑、恐惧、禁忌类表述：
  「不敢」「怕」「有毒吗」「能不能吃」「会不会伤」「有害吗」「安全吗」「能不能用」
- 话题属于饮食 / 健康 / 用药 / 电器 / 儿童 / 宠物 等后果不可逆领域

**核验要求**
1. 开头提出的顾虑，正文**必须正面回答**（不能只解释原理，回避「到底能不能做」）
2. 必须给出**适用条件与边界**（如「正规渠道原切可半生食，绞肉必须全熟」）
3. 若存在例外人群或风险场景，必须点明

**实证来源**
- 2026-09-07 牛排血水（严重）：A 段立「很多人这辈子不敢碰半生的牛排，怕的就是这口『血』」，
  全文只证「不是血」，**始终没回答「那到底能不能吃」**。IMA 称「最大硬伤」、
  千问称「开头承诺未兑现」。v1 Reviewer 判 P0=0、P1=0，完全漏判。

**漏判后果**：读者真实顾虑悬空；健康/安全类误导危害 > 知识性误差。

## G-02　绝对化 / 夸大表述

**触发信号（关键词扫描）**
- 绝对词：「不可能」「全看」「全都」「一定」「绝对」「必然」「永远」「无非」
- 说满的承诺：「就清爽多了」「彻底解决」「完全不会」「再也」「保证」
- 无例外的全称判断

**核验要求**
1. 每个绝对词都要问：**事实上有例外吗？** 有则必须软化（「很大程度」「多数情况」「通常」）
2. 效果承诺类表述须留余地，避免把「改善」写成「消除」

**实证来源**
- 2026-09-07 牛排血水（3 处）：
  - 「血液离开血管很快就会凝固，**不可能**还保持液态流出来」（绝对化）
  - 「这块肉有多红，**全看**它生前有多爱运动」（绝对化，忽略品种/部位/年龄等因素）
  - 「盘子**就清爽多了**」（效果说满）
  四家 AI 均指出，v1 Reviewer 零命中。

## G-03　看似合理的事实性错误

**触发信号**
- 涉及生物 / 物理 / 化学 / 医学特性的**定性描述**（尤其「因为 X 所以 Y」的常识推理）
- 用生活经验类比科学机制的地方
- 数字、比例、温度、时间等可核验量

**核验要求**
1. **禁止凭常识放行** —— 越是「听起来对」的表述越要回权威源核对
2. 特别注意「常识陷阱」：大众认知正确但细节错误（如「鸡不运动」是真的吗？）

**实证来源**
- 2026-09-07 牛排血水：初稿写「鸡胸肉**几乎不运动**，肌红蛋白少」——
  DS / 千问 / 豆包 3 家指出不准确，应为「以快肌纤维为主、不需持续供氧」。
  **v1 Reviewer 读到了这句话，却判 `attribution_checks.is_primary_cause=true`
  「红白肉区分标准确为肌红蛋白含量，归因主因正确」** ——
  不是没看见，是看见了判对。这是比漏看更严重的「判断标准松」。

## G-04　机制要素缺失（方向对但不完整）

**触发信号**
- 解释了「为什么会这样」，但中间环节跳步
- 用一句话概括多步骤过程

**核验要求**
逐环节追问：A → B 中间还有没有 C？读者按文中描述能自己推出来吗？

**实证来源**
- 2026-09-03 贝壳听海：漏「螺旋腔体多次谐振」环节，方向没错但解释力打折。
- 2026-09-02 刷牙橙汁：机制精度不足。

## G-05　引用 / 术语精度

**触发信号**
- 古书 / 论文 / 报道的引文或转述
- 医学、解剖、生理解剖类专有名词

**核验要求**
1. 引文**回原文逐字核**（「置井中」≠「埋进井里」）
2. 术语用字精确（「上腭」非「上颚」、「黏膜」非「粘膜」）
3. 概念归属正确（背景噪声 ≠ 白噪音）

**实证来源**
- 2026-09-03：《墨子·备穴》原文「置井中」被写成「埋进井里」。
- 2026-09-04：「上颚」应为「上腭」（「颚」=颌骨、「腭」=口腔顶壁），
  v2.6 两次独立 agent 均未检出。

## G-06　来源存在但细节未逐字核对（最高发）

**触发信号**
- 文中出现「研究表明」「XX 大学」「发表于 XX 年」「实验显示」等引用标记

**核验要求**
找到来源**只完成了一半**，必须核对：
- 干预物 / 受试者群体 / 实验条件 / 精确数值 / 是否有季节或场景限定

**实证来源**
- 2026-09-04 冰淇淋头痛：Reviewer 自述「已通过 WebSearch 证实该研究真实存在，可直接引用」。
  研究确实存在（BMJ 2002 Kaczorowski），但**「冰饮」实为冰淇淋、「学童」实为中学生、
  漏冬季实验与 79% 数据**。验证了来源存在，没验证细节准确。

## G-07　归因偏漏（只说次要原因）

**触发信号**
- 解释某现象成因，且该现象可能有多个成因

**核验要求**
问：这是**主因还是配角**？有没有更主要的原因被略过？

**实证来源**
- 2026-09-02 刷牙橙汁发苦：引述「橙汁含苦味黄酮类物质」无误，但遗漏主因
  **柠檬苦素（limonin，三萜类非黄酮）**。验证了「引述无误」，没验证「引述充分」。

## 使用方式（Reviewer 侧）

在 Step 5.9 中逐条过本清单，输出 `gap_checks` 数组，**7 条一条都不能少**：

```json
"gap_checks": [
  { "pattern_id": "G-01", "triggered": true,  "checked": true,
    "finding": "A段立『不敢碰半生牛排』的恐惧，正文未回答能否食用 → P1" },
  { "pattern_id": "G-02", "triggered": true,  "checked": true,
    "finding": "命中3处绝对化（不可能/全看/就清爽多了）→ P1" },
  { "pattern_id": "G-03", "triggered": true,  "checked": true,
    "finding": "『鸡胸肉几乎不运动』定性错误 → P1" },
  { "pattern_id": "G-04", "triggered": false, "checked": true, "finding": "" },
  { "pattern_id": "G-05", "triggered": false, "checked": true, "finding": "" },
  { "pattern_id": "G-06", "triggered": false, "checked": true, "finding": "" },
  { "pattern_id": "G-07", "triggered": false, "checked": true, "finding": "" }
]
```

- `triggered`：本文是否命中该类型的触发信号
- `checked`：是否**真的逐条核过**（不是扫一眼）
- `finding`：命中时的具体位置与判定；未命中留空

**脚本侧**：`validate_review.py` 校验 `gap_checks` 存在、条数等于本文件类型总数、
每条 `checked` 为 true。缺项即 FAIL —— 这是前三次补丁缺失的「执行校验」。
