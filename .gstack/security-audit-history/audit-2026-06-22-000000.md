## Executive Summary

daily-why 项目整体安全态势为 **中等风险 (C)**。未发现硬编码凭据或远程可利用漏洞。核心风险集中在 **路径遍历 (Path Traversal)** 和 **安全配置缺陷 (Security Misconfiguration)** 两类。最紧迫的问题是多个脚本允许用户通过 CLI 参数指定任意文件路径，结合 `subprocess.run()` 和文件写入操作，在自动化 prompt 执行上下文中可能被利用。推荐最优先修复 **F-004**（路径遍历）和 **F-009**（硬编码绝对路径）。

## Detailed Findings (All Confidence Levels)

---

### [F-001] Path Traversal via CLI args in run_pipeline.py
- **Category**: OWASP A01 (Broken Access Control) / STRIDE Elevation
- **Severity**: Medium
- **Confidence**: 7/10
- **Location**: `scripts/run_pipeline.py:94-111`
- **Description**: `step_validate(filepath)` and `step_update(filepath)` accept a user-supplied file path via `--file` argument. The path is directly appended to the subprocess command list without validation. While subprocess uses list form (no shell), a malicious path like `../../etc/passwd` could cause the validator to read files outside the workspace.
- **Exploit Scenario**: 
  1. Attacker controls the automation prompt
  2. Specifies `--file ../../../sensitive/file.md`
  3. validate_article.py reads and potentially exposes content
- **Reproduction Steps**: 
  ```bash
  python run_pipeline.py validate --file "../../../Windows/win.ini"
  ```
- **Remediation**: Add path validation: resolve and verify the file is within the workspace directory.
  ```python
  filepath = Path(filepath).resolve()
  if not str(filepath).startswith(str(WORKSPACE.resolve())):
      raise ValueError(f"Path outside workspace: {filepath}")
  ```
- **Priority**: P1 (this sprint)

---

### [F-002] Path Traversal via CLI args in auto_fix.py
- **Category**: OWASP A01 / STRIDE Elevation
- **Severity**: Medium
- **Confidence**: 8/10
- **Location**: `scripts/auto_fix.py:420-424`
- **Description**: `auto_fix.py` accepts a file path via CLI and constructs the target path. If relative, it resolves against workspace. If absolute, it's used directly without validation. This allows writes to arbitrary locations.
- **Exploit Scenario**:
  1. Attacker runs `python auto_fix.py C:/Users/admin/sensitive.json`
  2. auto_fix.py reads the file, applies fixes, and writes back with .bak created
  3. Could be used to corrupt or expose arbitrary files
- **Reproduction Steps**:
  ```bash
  python auto_fix.py "C:/Users/admin/Desktop/test.txt" --dry-run
  ```
- **Remediation**: Reject absolute paths outside the workspace. Validate resolved path is within workspace.
- **Priority**: P1 (this sprint)

---

### [F-003] Untrusted Content in Subprocess (validate_article.py)
- **Category**: OWASP A03 (Injection)
- **Severity**: Low
- **Confidence**: 6/10
- **Location**: `scripts/validate_article.py:466-484`
- **Description**: `_fetch_related_cases()` constructs a query string from P0/P1 error messages (`result.p0 + result.p1`), then passes it as a command-line argument to case_matcher.py via subprocess.run(). Article content could contain special characters, though the list-form subprocess call mitigates shell injection.
- **Exploit Scenario**:
  1. Article contains P0 error message with unusual characters
  2. Query string is passed to subprocess
  3. Low risk due to list-form invocation
- **Reproduction Steps**: Create article triggering P0 error with `--` prefix in content
- **Remediation**: Sanitize query before passing to subprocess, or use stdin instead of CLI args.
- **Priority**: P3 (backlog)

---

### [F-004] Hardcoded Absolute Paths (Python Interpreter)
- **Category**: OWASP A05 (Security Misconfiguration)
- **Severity**: Medium
- **Confidence**: 9/10
- **Location**: 
  - `scripts/generate_prompt.py:36`: `PYTHON_PATH = r"C:/Users/admin/.workbuddy/binaries/python/versions/3.13.12/python.exe"`
  - `scripts/generate_prompt.py:132,170`: Embedded in generated prompts
  - `scripts/orchestrator.py:34`: Same hardcoded path
- **Description**: The Python interpreter path is hardcoded in multiple locations. This:
  1. Binds execution to one specific Python installation
  2. Could allow an attacker who controls the Python binary at that path to execute arbitrary code
  3. Breaks on any machine other than the original developer's
- **Remediation**: Use `sys.executable` (as already done in run_pipeline.py:42 and auto_fix.py:354)
- **Priority**: P1 (this sprint)

---

### [F-005] Hardcoded Workspace Absolute Paths
- **Category**: OWASP A05 (Security Misconfiguration)
- **Severity**: Low
- **Confidence**: 9/10
- **Location**: 13 out of 14 scripts hardcode `F:\WorkBuddy\daily-why`
- **Description**: Nearly every script contains `WORKSPACE = Path(r"F:\WorkBuddy\daily-why")`. This prevents code reuse, portability, and makes path traversal validation harder.
- **Remediation**: Use environment variable `DAILY_WHY_WORKSPACE` or relative paths from `__file__`.
- **Priority**: P2 (next sprint)

### [F-006] File Write Path Traversal (auto_fix.py)
- **Category**: OWASP A01 / STRIDE Tampering
- **Severity**: Medium
- **Confidence**: 8/10
- **Location**: `scripts/auto_fix.py:326-336`
- **Description**: `auto_fix()` writes the fixed content back to `filepath` which comes from user-controlled CLI args. The backup function creates a `.bak` file in the same directory. Combined with path traversal, this could write files to arbitrary locations.
- **Remediation**: Same as F-002 — validate resolved path is within workspace.
- **Priority**: P1 (this sprint)

### [F-007] Message Handler Path Traversal
- **Category**: OWASP A01
- **Severity**: Low
- **Confidence**: 7/10
- **Location**: `scripts/message_handler.py:38-52`
- **Description**: Message filenames are constructed from user-controlled `from_agent` and `to_agent` values: `f"{from_agent}_to_{to_agent}_{timestamp}"`. If an agent name contains path traversal sequences (e.g., `../../config`), the message file could be written outside the messages/ directory.
- **Remediation**: Sanitize agent names — allow only `[a-zA-Z0-9_-]+`.
- **Priority**: P2 (next sprint)

---

### [F-008] Bare Except in Multiple Locations
- **Category**: OWASP A05
- **Severity**: Low
- **Confidence**: 5/10
- **Location**: `topic_utils.py:68`, `orchestrator.py:52`, `prepare_topics.py` (via topic_utils)
- **Description**: `except Exception:` (not bare except, but still wide) and `except:` patterns silently swallow errors.
- **Remediation**: Log exceptions at minimum; use specific exception types.
- **Priority**: P3 (backlog)

---

### [F-009] No Integrity Verification Between Pipeline Stages
- **Category**: OWASP A08 (Software and Data Integrity Failures)
- **Severity**: Low
- **Confidence**: 7/10
- **Location**: Pipeline workflow (run_pipeline.py, orchestrator.py)
- **Description**: No checksums or integrity verification between pipeline stages. An attacker who modifies the article file between the write step and the validate step would not be detected.
- **Remediation**: Compute and verify SHA256 of article before/after each stage. Store hash in orchestrator-state.json.
- **Priority**: P3 (backlog)

### [F-010] File Glob Injection via workspace.glob()
- **Category**: OWASP A03 (Injection) — Low
- **Severity**: Info
- **Confidence**: 5/10
- **Location**: 
  - `validate_article.py:509`: `workspace.glob("articles/**/*-每日冷知识*.md")`
  - `validate_article.py:521`: `workspace.glob(f"articles/**/{today}-每日冷知识*.md")`
  - `check_topic.py:180`: `workspace.glob("articles/**/*-每日冷知识*.md")`
  - `send_daily_why.py:103`: `WORKSPACE.glob("articles/**/*-每日冷知识*.md")`
- **Description**: The `today` variable in validate_article.py:521 comes from `datetime.now().strftime("%Y-%m-%d")` which is safe. All glob patterns are constant strings — no user input interpolation.
- **Verdict**: **FALSE POSITIVE — SAFE**. After active verification, all glob patterns use hardcoded strings or safely-derived values. No injection vector.
- **Priority**: N/A

### [F-011] prompt 中的命令注入风险 (generate_prompt.py 生成的 prompt)
- **Category**: OWASP A03 (Injection) — Theoretical
- **Severity**: Info
- **Confidence**: 3/10
- **Location**: `generate_prompt.py:134-161` and `generate_prompt.py:172-188`
- **Description**: The generated automation prompt contains shell-like commands:
  ```
  运行 `C:/Users/admin/.workbuddy/binaries/python/versions/3.13.12/python.exe F:/WorkBuddy/daily-why/scripts/validate_article.py`
  ```
  These commands are executed by the LLM Agent, not by a shell. The LLM Agent interprets them conceptually. If the Agent's execution environment runs these via shell, it would be using hardcoded paths (not user input), so the injection risk is negligible.
- **Verdict**: **THEORETICAL — NOT EXPLOITABLE**. No user input reaches command construction.
- **Priority**: N/A
