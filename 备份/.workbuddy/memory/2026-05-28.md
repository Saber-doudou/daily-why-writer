## GitHub 推送踩坑记录
- 系统 PATH 中 npm 包装的 `gh`（`~/.workbuddy/binaries/node/.../gh`）优先于官方 `gh` CLI
- npm 版 `gh` 有 bug，`auth status`/`auth login` 会崩
- 官方 gh CLI 路径：`C:/Program Files\GitHub CLI\gh.exe`
- WorkBuddy 默认沙箱会屏蔽 Program Files 路径，需要用户手动开放权限才能访问
- GitHub 推送文件用 `gh api repos/OWNER/REPO/contents/PATH -X PUT` + base64 编码
