### 脚本增强方向（减少 token）
- 核心目标：用 Python 脚本替代 prompt 中消耗 token 的部分
- 识别出 3 个可脚本化的 token 节省点：
  1. 话题扫描（prepare_topics.py）→ 省 ~500 token/次（从 prompt 中移除话题列表）
  2. 格式质检（validate_article.py）→ 省 ~200 token/次（从 prompt 中移除格式规则）
  3. 历史更新（update_history.py）→ 省 ~100 token/次（AI 不用手动更新 memory.md）
- 预估：prompt 从 ~600 token 精简到 ~200 token，年节省 ~100K token
