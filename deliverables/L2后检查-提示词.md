## 完整流程（我的执行规范）

### 我的角色边界（先声明，防越界）

1. **只检查、只报告**。不修改任何文件、不改脚本、不碰 git 提交/推送。
2. **绝不触发 L3**。L3 由您自己手动跑。我报告末尾只给「可否进入 L3」判定，不代劳。
3. **不猜、不抽样**。每个判据都要有实际命令 + 原始输出片段作证据；跑不到就明写「未验证」，不写「应该没问题」。
4. 全部读完再下结论，禁止用「印象里是对的」代替验证。

### ⚠️ 环境注意（先读，避免踩坑）

- **本机 Bash 不可用**（`dirname`/`head`/`grep`/`ls` 全 command not found），一律改用
  `C:/Users/admin/.workbuddy/binaries/python/versions/3.13.12/python.exe` 跑 Python 脚本。
- **`l3_publish.py` 的日期是位置参数**，不是 `--date`。写成 `--date` 会 rc=2 报
  `unrecognized arguments`。
- **`--dry-run` 遇到「当日已发布」会直接跳过整个 Phase 0-5**，根本跑不到 Phase 1。
  想验提取器必须直接调用内部函数（见步骤 2），**不要**用 `--dry-run`。
- **任何 `l3_publish.py` 调用都会写真实 `l3_run.log`**（即使只是 Phase 0 跳过，也会写 4 行）。
  检查期间若跑过 CLI，收尾必须核对日志行数并清理。

- **判据 A**：v1、v2、学习总结三者都存在。任一缺失即 P0，直接收尾报告。

#### 步骤 1 · 契约锚点（本次修复核心，第一位检查）

背景：L2 v3.4 新增强约束，学习总结必须含**逐字** `## 改进点` 二级标题，其下用 `- ` 列表。

```python
import re, sys, pathlib
t = pathlib.Path(r'F:\WorkBuddy\daily-why\投喂素材\YYYYMMDD\学习总结.md').read_text(encoding='utf-8')
m = re.search(r'^## 改进点\s*$\n(.*?)(?=^##\s|\Z)', t, re.M | re.S)
n = len(re.findall(r'^- .+', m.group(1), re.M)) if m else 0
print(f'锚点={"有" if m else "无"} 条目={n}')
print('全部二级标题:', re.findall(r'^##\s+(.{0,50})', t, re.M))
```

- **判据 B**：输出 `锚点=有 条目=N` 且 N ≥ 1 → 通过。
- `锚点=无` → **P0**，L2 v3.4 约束未生效，须人工补验 + 修复。
- 标题是 `### 改进点` 或 `## 一、改进点` → **P1**（漂移边缘，L3 多模式回退能兜住）。
- **基线参考**：09-17 是老格式（`一、四 AI 核心差距…`），因为锚点是当日下午才加的；
  锚点首次真实生效应在 **09-18** 的 L2。

#### 步骤 2 · L3 提取器实测（吃真实文件，不是造数据）

**不要用 CLI。** 直接调内部函数，绕过 Phase 0 的已发布短路，且不写日志：

```python
import sys, pathlib, contextlib, io
sys.stdout.reconfigure(encoding='utf-8')
sys.path.insert(0, r'F:\WorkBuddy\daily-why\scripts')
import l3_publish as l3

base = pathlib.Path(r'F:\WorkBuddy\daily-why')
v1 = base / 'articles' / 'YYYY-MM' / 'YYYY-MM-DD-每日冷知识-{话题}.md'
v2 = base / 'articles' / 'YYYY-MM' / 'YYYY-MM-DD-优化版-每日冷知识-{话题}.md'
sm = base / '投喂素材' / 'YYYYMMDD' / '学习总结.md'

# ★ 必须显式传 log_path，否则会写真实 l3_run.log
res = l3.Result(log_path=r'F:\WorkBuddy\daily-why\scripts\_tmp_test.log')
buf = io.StringIO()
with contextlib.redirect_stdout(buf):
    try:
        rc = l3.phase1_match_check(v1, v2, sm, True, res)
    except SystemExit as e:
        rc = f'SystemExit({e.code})'

print('content =', rc['content'])
```

- **判据 C**：`content['ok']` 为 `True`，且 `content['total']` ≥ 1，`content['source']` 有值。
  - 通过样例：`total=6, source='三、v2 改写要点（已落盘，char_count=<实测>≤690）'`
  （样例值用 `<实测>` 占位，勿写死具体数字——09-17 曾写死 632 致次日即过期，09-18 修复）
  - **注**：`IMPROVEMENT_HEADING_PATTERNS` / `BULLET_RE` 是**函数内局部常量**，模块级取不到，
    别试图 `l3.IMPROVEMENT_HEADING_PATTERNS`（会 AttributeError，属正常）。
- 跑完记得删 `scripts/_tmp_test.log`，并核对 `l3_run.log` 行数未变。
