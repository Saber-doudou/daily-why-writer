## 五、外部经验调研（2026-10-13 检索）

1. **三级漏斗**（NVIDIA NeMo Curator / DOT Data Labs）：精确匹配 → 模糊（字符 n-gram / MinHash）→ 语义（embedding，阈值约 0.80 至 0.95）。n-gram 指纹对同义替换无感（「显著」与「明显」指纹完全不重合），与今日根因同构：字面层过关不等于语义层过关。
2. **短文本不要上 SimHash**：政策快报平台实践（>500 字正文用 SimHash，短文本用 MinHash / 语义向量）；多方资料指出 SimHash 对短文本效果不佳。本项目话题 10 至 30 字，任何「上 SimHash」的提议应直接否决。
3. **中文同义词资源**：哈工大同义词词林（Cilin）及 Python 实现（CilinSimilarity / WordSimilarity / synonyms）可作概念表种子；但 synonyms 库依赖 jieba 分词，与项目「零新增重依赖」约束冲突。建议以 JSON 概念表落地，Cilin 仅作种子参考。
4. **blogcog 内容去重六条**（内容管线场景，与本项目最同构）：相似度门禁放在写作前（已做到）；多信号混合检索（语义 + 关键词 + 分类 + 实体）；**记录被拒选题**（素材池已做）；相似度分低/中/高三档而非二元判定（角度模式已做，但只报 top-1，要修）；**度量系统质量**（追踪警告采纳率、漏判率、误杀率，本次事件无任何度量数据，要补）；「标题独特不等于价值独特，批准前要求说明增量」。
5. **今日头条自媒体三层框架**：编号级（选题终身绑定）、系列级（同主题域 30 天限 1 篇）、感知级（关键词重叠 >60% 且同主题域判重）。系列级思想可作概念表大类词的降档提示，不作硬拦。
6. **本项目 09-15 既有调研**（deliverables/2026-09-15-去重防线外部经验调研.md）四级防线模型（检测/拦截/数据治理/验证）：今日失效的是检测层；验证层 dedup_selftest 从未喂过「同义改写」样本，属同一教训的第二次应验——整改必须含回归用例。

### T1 概念重叠检测（修正版 S1）— P0

- 新文件 `config/topic_concepts.json`，schema 分两层词：
```json
{
  "concepts": {
    "牛排血水":   {"generic": ["牛排", "牛肉"], "specific": ["血水", "红色汁液", "渗出液", "肉汁"]},
    "海水咸":     {"generic": ["海水", "大海", "海洋"], "specific": ["咸", "盐分", "盐"]},
    "关节痛天气": {"generic": ["关节", "膝盖"], "specific": ["预报天气", "天气预报", "阴雨天", "变天"]}
  }
}
```
  - generic = 大类词，仅用于降档提示，不拦截；specific = 现象词，双侧命中才拦截。
  - **机制词禁止入表**（如肌红蛋白、氧合）：同机制不同现象（真空包装绽色 vs 血水）必须放行。
- `check_topic.py` 新增 `load_concepts()` / `extract_concept_hits(text)` / `check_concept_overlap(...)`，在检查 3 之后插入检查 4。
- 判定规则（替换 hy3 的「≥2」规则）：
  - 新话题与某已有话题命中同一 concept，且双方 specific 各 ≥1 → **硬重复**（exit 1，`--angle` 不可覆盖，与字符包含率 ≥70% 同等效力）；
  - 仅 generic 命中 → 不提示不拦（同大类是常态，避免噪音）；
  - 概念文件缺失或为空 → 降级为现状行为 + stderr 醒目警告（不静默，防 Silent Fail-Open）。
- 首批只收录上表 3 个有实证依据的家族；增量来源：落选回写、L2 投喂信号、月度复盘。**禁止**按「近 30 天高频话题」批量扩表（误杀风险）。
- 回退：删除检查 4 调用即回到现状。

## 八、风险与回退

- **误杀风险**：specific 双侧命中已把 A4 至 A7 全部排除在外；即便如此，T5 中 A4 至 A7 全放行仍是验收必要条件，缺一不可。
- **概念表腐化**：无增量机制则数月后失效。缓解：T4 决策日志 + 落选回写信号 + 月度复盘补表；宁缺毋滥，首批仅 3 族。
- **通用语义层缺口（诚实声明）**：概念表是高价值家族的针对性补丁，不是通用语义引擎；未被收录家族的「换说法」重复仍可能漏。Phase 2 决策项（本次不做，Master 择期评估）：① text2vec CoSENT 中文模型做语义向量校验（效果最好，但数百 MB 依赖，与零依赖约束冲突）；② 复用 L2 四 AI 投喂环节兼做去重交叉验证（零新增依赖，推荐优先评估）。
- **回退粒度**：T1 至 T4 各自独立可回退；T1/T2/T3 任一上线，即使 T4/T5 延后，也不降低现有防护。
