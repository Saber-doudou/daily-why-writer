## 四、执行过程中的环境坑（已修复，重要）

1. **沙箱 git ref 落盘静默失败**（与历史记忆同源）：`checkout -b` 与 `commit` 写分支 ref 均可能静默丢失（首次 checkout 产生空分支、commit 后 ref 未更新）。修复：扁平分支名 + 完整 40 位 hash 强写 `refs/heads/`。**后续每次 git 操作后必须验证 ref 落盘**。
2. **ref 文件必须写完整 40 位 hash**：短 hash（`931487a`）在 ref 文件中无效，git 报 "ignoring broken ref"。
