## 四、技能未使用根因确认（查证#3）

### 4.1 证据链

```
usage-log.json 共6条记录
→ 搜索 "daily" → 0条匹配
→ 搜索 "daily-why" → 0条匹配
→ 搜索 "publish" → 仅 daily-why-publish 记录(关键词触发)
→ daily-why-writer → 0次工具调用
→ daily-why-feed-learning → 0次工具调用
```

### 4.2 根因

`automation-1778312519754` 的 prompt 中包含的是**自然语言描述**"加载 daily-why-writer skill"，而非 `Skill("daily-why-writer")` **工具调用指令**。模型按描述执行了 A+C+F 规则（因为 prompt 内联了规则副本），但从未触发 Skill 工具。

### 4.3 影响面

| 影响 | 详细 |
|------|------|
| **SKILL.md 漂移** | 写作指导变更不传至自动化（如新增的 FP-45 约束、§39 检查） |
| **CHECKLIST/FORBIDDEN 存活** | 这两个文件因 Reviewer 阶段按绝对路径现场 Read，保持最新 ✅ |
| **usage-log 为空** | 无法追踪技能实际使用频率，不能做数据驱动的优化决策 |
| **补救已完成** | 今天 11:35 部署的 generate_prompt.py 改动明天 09:40 首次生效 |
